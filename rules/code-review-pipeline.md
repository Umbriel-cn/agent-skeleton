# 多 agent 协作：文件分级 + agent 分级 + 沙箱流程

> 选择层（默认关）。单人单 agent 用不上；多 agent 家庭/团队开。

## 文件分级（S 级）
| 级别 | 示例 | 改动要求 |
|---|---|---|
| S0 | 文档/注释 | 直接改 |
| S1 | 常规代码 | 改后 diff 自查 |
| S2 | 配置/脚本 | 备份→改→验证→报告 |
| S3 | 凭证/身份/核心规则 | 先出方案让用户确认 |

## agent 分级（L 级）
| 级别 | 角色 | 职责 |
|---|---|---|
| L0 | 用户 | 最终 review 与决策 |
| L1 | 主脑 | 思考、判断、调度 |
| L2 | 执行体 | 代码/运维/内容，按领域分 |
| L3 | 调度/知识 | 任务分配、记忆整理 |

## 沙箱流程
非 S0/S1 的改动：备份 → 改 → 验证（最简调用实测）→ 报告 + diff → 用户 review → 提交 → 记录
紧急安全修复：先修，事后 24h 内补完整流程并说明跳过了哪步（R6）。
